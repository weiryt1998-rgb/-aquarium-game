# 🐠 เกมเลี้ยงปลาในตู้ปลา

เกมเลี้ยงปลา 3 มิติที่เล่นผ่านเว็บเบราว์เซอร์ สร้างด้วย **Three.js + WebGL + Vite** (ไม่ใช้ Unity หรือ Unreal)
ผู้เล่นเลี้ยงปลา ตกแต่งตู้ และดูแลให้ปลามีความสุข

**▶ เล่นออนไลน์:** https://weiryt1998-rgb.github.io/-aquarium-game/

## วิธีรัน

ต้องมี Node.js 20.19 ขึ้นไป

```bash
npm install      # ติดตั้งครั้งแรก
npm run dev      # เปิดเกมที่ http://localhost:5173
npm run build    # build ไฟล์สำหรับเอาขึ้นเว็บ (ได้โฟลเดอร์ dist/)
npm run preview  # ทดลองเปิดไฟล์ที่ build แล้ว
```

## ☁️ เซฟกลาง (เล่นต่อได้ทุกอุปกรณ์)

เกมบันทึกความคืบหน้าไว้บน **Cloud Firestore** เป็นเซฟกลางชุดเดียว (`gameSaves/global`) ผู้เล่นทุกคนกรอก **รหัสผ่านเกม** เดียวกัน
(บัญชีผู้เล่นหลักบัญชีเดียวใน Firebase Authentication) แล้วเล่นเซฟเดียวกัน เห็นข้อมูลล่าสุดตรงกันแบบเรียลไทม์

- ใช้ Firebase แผน **Spark (ฟรี)** เท่านั้น — ไม่ใช้ Cloud Functions และไม่ใช้ SQL
- บันทึกด้วย Firestore transaction + เลข `revision` กันเซฟเก่าทับเซฟใหม่ · Security Rules อนุญาตเฉพาะ UID บัญชีหลัก
- ป้ายสถานะมุมขวาบนบอกว่า บันทึกแล้ว / กำลังบันทึก / บันทึกไม่สำเร็จ / ออฟไลน์
- สำรองอัตโนมัติวันละครั้งและก่อนรีเซ็ต/กู้คืน · กู้คืนได้จากเมนู ☰ → เซฟคลาวด์
- เซฟเก่าในเบราว์เซอร์ถูกถามก่อนนำเข้า และไม่ทับเซฟกลางที่มีข้อมูลแล้ว

ขั้นตอนตั้งค่า Firebase Console, วิธีตั้งรหัสผ่านเกม, โควตาฟรี และวิธีทดสอบ: **[docs/CLOUD_SAVE.md](docs/CLOUD_SAVE.md)**

```bash
npm run set-player-uid -- <UID>   # ใส่ UID บัญชีผู้เล่นหลักลง firestore.rules
npm run check:firebase            # ตรวจค่าตั้ง Firebase ในเครื่อง
npm run deploy                    # deploy เฉพาะ Firestore Security Rules (ตรวจ UID ก่อนเสมอ)

npm test                # unit tests
npm run test:rules      # Security Rules (ต้องมี Java 21+)
npm run test:e2e        # เปิดเกมจริงใน Chrome หลายเครื่องจำลอง บน Firebase Emulator
```

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
| --- | --- |
| เลี้ยงปลาและเพิ่มจำนวนปลา | สัตว์น้ำที่ขายอยู่ 12 สายพันธุ์ แต่ละชนิดมีสี รูปร่าง ระดับน้ำที่ชอบ และพฤติกรรมต่างกัน (เช่น ปลาสอดว่ายเป็นฝูง ปูเดินตะแคงเก็บอาหารบนพื้น กระเบนกระพือครีบ) ปลาโตจากลูกปลาเป็นตัวเต็มวัย เลือกเพศได้ตอนซื้อ เมื่อมีตัวผู้กับตัวเมียชนิดเดียวกันที่มีความสุข ตัวเมียจะตั้งท้องแล้วคลอดลูกเมื่อครบกำหนด (`CONFIG.breeding.gestation`) |
| ตกแต่งตู้ปลา | พืชน้ำ หิน ขอนไม้ ปราสาท หีบสมบัติ ปะการัง หัวทรายออกซิเจน วางบนกริด ลากย้าย หมุน และขายคืนได้ |
| ให้อาหารและดูแลปลา | ความอิ่ม สุขภาพ ความสุข และความสะอาดของน้ำ อาหารที่เหลือจะเน่าทำให้น้ำขุ่น ปลาที่ถูกปล่อยปละจะค่อย ๆ หิว → อดอาหาร → ป่วย → อาการหนัก โดยแจ้งเตือนทุกขั้นพร้อมวิธีแก้และเวลาที่เหลือ (ละเลยทั้งอาหารและน้ำ ปลาอยู่ได้ราว 40 นาที) |
| ระบบเงินและร้านค้า | ปลาที่มีความสุขผลิตเหรียญ (แตะเพื่อเก็บ) มีภารกิจรายวัน รางวัลประจำวัน สมุดสะสมปลา ตู้ 4 ขนาด 4 สไตล์ที่ปลดล็อกได้ (โอเชียนบลู · วอลนัทการ์เดน · คอรัลรีฟ · รอยัลอะบิส — ดูภาพตัวอย่างในร้านก่อนซื้อได้ แต่ละตู้มีปลาและของตกแต่งแยกกัน) และแลกเหรียญเป็นเพชร |
| อื่น ๆ | เซฟกลางบนคลาวด์ (เล่นต่อได้ทุกอุปกรณ์), ได้เหรียญตอนออฟไลน์, ถ่ายภาพตู้, ติดตามปลาด้วยกล้อง, ตั้งชื่อปลา, เสียงสังเคราะห์ (ไม่ต้องมีไฟล์เสียง), ปรับคุณภาพกราฟิก, รองรับมือถือ |

ส่วนกราฟิกใต้น้ำ: ลายแสงระยิบระยับบนพื้น (caustics), ลำแสงจากผิวน้ำ, ฟองอากาศ, หมอกใต้น้ำที่ขุ่นขึ้นเมื่อน้ำสกปรก, พืชน้ำโยกไหว, ปลาส่ายหางด้วย vertex shader

## Simulation Engine (`src/sim/`)

แยกการคำนวณระบบนิเวศออกจากการแสดงผลชัดเจน:

| ชั้น | ทำอะไร | ความถี่ |
| --- | --- | --- |
| `src/sim/` (TypeScript) | ความอิ่ม สุขภาพ การโต ความสุข เหรียญ ความสะอาดน้ำ อาการ ผสมพันธุ์ คลอด ตาย | ทุก `CONFIG.sim.tickSeconds` (1 วินาทีเกม) ไม่ใช่ทุกเฟรม |
| Three.js (`entities/`, `world/`, `systems/`) | ว่าย ท่าทาง เอฟเฟกต์ แสดงผลเหตุการณ์จาก engine (เหรียญลอย ปลาตาย ลูกเกิด แจ้งเตือน) | ทุกเฟรม |

- `TankSimulation.advance(dt)` สะสมเวลาจริงแล้วคำนวณเฉพาะเมื่อครบจังหวะ (เฟรมส่วนใหญ่ไม่คำนวณอะไร) จากนั้นฝั่งเกมอ่าน `drainEvents()`
  ไปแสดงผลและส่งคำสั่งให้เซฟกลาง — engine ไม่รู้จัก Three.js, DOM, เสียง หรือเซฟกลาง
- `tsconfig.json` ไม่เปิดชนิดข้อมูลของ DOM ให้ `src/sim/` และ `npm run typecheck` จะฟ้องถ้าโค้ดจำลองไปแตะ `document`/`window`
  ไฟล์ `.ts` รันได้ตรงทั้งใน Vite และ Node (ตัด type ออกเอง) ไม่ต้อง build แยก — เทสต์อยู่ที่ `tests/unit/simulation.test.js`
- สมดุลการดูแล (`CONFIG.care`): หิว 30% → อดอาหาร 10% (สุขภาพเริ่มลด) → ป่วย 50% → อาการหนัก 20% (สุขภาพลดช้าลงเพื่อให้เวลาแก้ไข)
  ละเลยทั้งอาหารและน้ำ ปลาจะหิวในราว 9 นาที ป่วยราว 28 นาที อาการหนักราว 34 นาที และตายราว 41 นาที
  ระหว่างออฟไลน์ปลาไม่เสียสุขภาพ (`CONFIG.offline`)

## Fish Life AI (`src/ai/`)

ปลาที่ว่ายน้ำทุกตัวมีพฤติกรรมของตัวเอง (ปูที่เดินพื้นยังใช้การเดินแบบเดิมใน `entities/Fish.js`)

| ส่วน | รายละเอียด |
| --- | --- |
| ค่าสถานะ | ความหิว สุขภาพ อายุ (จาก Simulation Engine / เซฟ) + พลังงาน ความเครียด (ค่าระยะสั้นใน AI) + บุคลิก |
| บุคลิก (`personality.ts`) | ขี้สงสัย · ขี้อาย · ชอบเข้าสังคม · ใจเย็น · กระฉับกระเฉง — คำนวณจาก ID ปลา (ไม่ต้องเพิ่มข้อมูลในเซฟ ได้บุคลิกเดิมทุกเครื่อง) มีผลต่อความเร็ว อัตราเลี้ยว ระยะห่างจากปลาอื่น ความถี่การสำรวจ ระยะมองเห็นอาหาร ความไวต่อสิ่งรบกวน |
| FSM (`FishAgent.ts`) | Idle · Explore · SeekFood · Eat · Rest · School · Avoid · Hide — ตัดสินใจทุก ~0.35–0.7 วินาที (แต่ละตัวไม่พร้อมกัน) มีเวลาขั้นต่ำต่อสถานะ + โบนัสให้ทำต่อ (ไม่เปลี่ยนใจถี่) ยกเว้นเหตุด่วน: หิวแล้วเห็นอาหาร ตกใจ จะชน |
| การว่าย | Steering (seek/arrive, Separation/Alignment/Cohesion, หลบกระจก/พื้น/ของตกแต่ง) → หมุนหัวได้ไม่เกินอัตราสูงสุดของสายพันธุ์ × บุคลิก → ว่ายไปตามทิศหัว (ไม่ไถลข้าง) ปรับความลึกด้วยครีบ ลอยขึ้นลงเบา ๆ ตอนพยุงตัว แล้วบังคับให้อยู่ในน้ำเสมอ |
| อาหาร | ใช้ระบบให้อาหารเดิม (`FoodSystem`) — โรยอาหารแล้วปลาที่หิวแถวนั้นรู้ตัว เลือกเม็ดที่ใกล้และมีปลาตัวอื่นเล็งน้อย (ไม่แห่ไปจุดเดียว) กินแล้ว Simulation Engine เพิ่มความอิ่ม |
| สิ่งรบกวน | ทำความสะอาดตู้ / ปลาใหม่ลงตู้ / โรยอาหาร → ความเครียดเพิ่มตามบุคลิก เครียดมากจะไปหลบในพุ่มพืชหรือข้างของตกแต่ง |
| ประสิทธิภาพ | คำนวณ 30 ครั้ง/วินาที (fixed timestep) เกลี่ยภาพระหว่างจังหวะ, Spatial Grid หาเพื่อนบ้าน, ไม่สร้าง object ใหม่ในลูป — ปลา 300 ตัว ≈ 2 ms ต่อจังหวะ |

- ท่าทางยังใช้ของเดิมตามโมเดล: shader ว่ายน้ำ (ปลาสอด `model.motion`), แอนิเมชันในไฟล์ (mixer), โครงกระดูก (ม้าน้ำ) — AI ส่งความเร็วและอัตราเลี้ยวไปขับท่าทางเหล่านี้
- การ์ดข้อมูลปลาแสดงบุคลิก สิ่งที่กำลังทำ พลังงาน และความเครียด
- เทสต์: `tests/unit/fishAI.test.js` (ไม่ทะลุ, เลี้ยวนุ่ม, กินอาหาร, บุคลิก, ประสิทธิภาพ) และ e2e ข้อ 15e (ในเกมจริง)

## ใส่โมเดล .glb ภายหลัง

1. วางไฟล์ตามชื่อในตาราง [public/models/README.md](public/models/README.md) เช่น `public/models/fish/goldfish.glb`
2. เสร็จแล้ว เกมจะใช้ไฟล์นั้นแทนโมเดลชั่วคราว รวมถึงรูปตัวอย่างในร้านค้าด้วย (ถ้ารัน `npm run dev` อยู่ หน้าเว็บจะรีโหลดเอง)

ไม่ต้องแก้โค้ด ถ้าจะเปลี่ยนชื่อไฟล์ ทิศของโมเดล หรือขนาด ให้แก้ฟิลด์ `model` ใน `src/data/fish.js` หรือ `src/data/decor.js`

```js
model: { url: 'models/fish/betta.glb', rotation: [0, -Math.PI / 2, 0], scale: 1.1 }
```

ไฟล์กลางอย่าง `fish.glb`, `plant.glb`, `rock.glb` ใช้แทนได้ทุกชนิดในหมวดนั้น ถ้ายังไม่มีไฟล์เฉพาะของชนิดนั้น

## ปลา Balloon Molly (โมเดลจากโค้ด)

ปลาสอด 5 สี — ดัลเมเชียน, หัวแดง, ทอง, คาลิโก้, โกลด์ดัสต์ (`molly_<สี>`) ใช้โมเดลเดียวกันที่สร้างด้วยโค้ดทั้งหมดใน `src/models/molly/` ไม่ต้องมีไฟล์ .glb

| ไฟล์ | หน้าที่ |
| --- | --- |
| `MollyModel.js` | `createMolly({ variant, detail, animated })` — ประกอบ mesh + วัสดุ PBR (clearcoat, ประกายมุก) |
| `mollyShape.js` | รูปทรงลำตัว ปาก ตา ครีบทั้ง 7 ชิ้น (ปรับรูปร่างได้จากตาราง `TOP` / `BOTTOM` / `WIDTH`) |
| `mollyTextures.js` | วาดลายเกล็ด, normal map, ลายจุด/ลายบั้ง, ก้านครีบ, ม่านตา ตอนรันไทม์ |
| `mollySwim.js` | แอนิเมชันว่ายใน vertex shader: ลำตัวเป็นคลื่น สะบัดหาง ครีบอกพัด โค้งตัวตอนเลี้ยว |
| `variants.js` | ชุดสี: `dalmatian`, `redhead`, `golden`, `calico`, `golddust`, `black`, `white`, `silver` (ลายจุดหลายชั้น + สีหัว + ลายบั้ง/หินอ่อน เช่นดัลเมเชียน) |

- **หน้าทดสอบ**: `npm run dev` แล้วเปิด `/preview/molly.html` — หมุนดูรอบตัว, ดูการเลี้ยว, ใส่ปลาหลายสิบตัวเพื่อดู FPS, สลับสีและระดับรายละเอียด
  (หน้านี้ไม่ถูกรวมในไฟล์ build)
- **ความละเอียดตามคุณภาพกราฟิก**: สูง ≈ 10k สามเหลี่ยม/ตัว, ต่ำ (มือถือ) ≈ 2.7k สามเหลี่ยม/ตัว และใช้วัสดุที่เบากว่า
  ปลา 1 ตัว = 3 draw call; geometry และ texture ใช้ร่วมกันทุกตัว แอนิเมชันทั้งหมดทำบน GPU
- **เพิ่มสีอื่นเข้าร้านค้า**: เพิ่ม `mollySpecies({ variant, ... })` ใน `src/data/fish.js`
- **ผสมข้ามสี** (`genetics.js`): ปลาสอดทุกสีอยู่กลุ่มพันธุ์ `molly` ผสมสีเดียวกัน = ลูกพันธุ์แท้สีเดิม
  ผสมต่างสี (หรือมีพ่อ/แม่เป็นลูกผสม) = "ปลาสอดลูกผสม" (`molly_hybrid` ไม่ขายในร้าน) ที่เก็บยีนสีไว้ใน `fish.genes`
  ลูกได้สีตัว สีครีบ สีหัว และชั้นลายจุดจากพ่อแม่ บางครั้งสีผสมกันเป็นสีกลาง มีโอกาสกลายพันธุ์ 15%
  และลายจุดของแต่ละตัวไม่ซ้ำกัน ยีนของลูกกำหนดตอนตั้งท้อง (`fish.fetus` ของแม่) จึงคลอดได้แม้ตัวพ่อถูกขายไปแล้ว
  หน้าทดสอบมีปุ่ม "🧬 ลูกผสม (สุ่มใหม่)" ไว้ดูตัวอย่าง
- **ลูกปลา**: ใช้รูปทรงลูกปลาแรกเกิด `molly_baby.glb` (ตัวเรียว ตาโต ครีบใส ย้อมสีตามสายพันธุ์/ยีนแบบเดียวกัน)
  จนโตได้ 60% (`procedural.babyUntil`) แล้วเปลี่ยนเป็นทรงบอลลูน — หน้าทดสอบมีปุ่มสลับ "ตัวเต็มวัย / ลูกปลา"
- ถ้าวางไฟล์ `public/models/fish/molly_dalmatian.glb` ภายหลัง เกมจะใช้ไฟล์นั้นแทนโมเดลจากโค้ด

## ปรับแต่ง

- **สมดุลเกม**: `src/config.js` เช่น `timeScale: 10` ทำให้เวลาในเกมเร็วขึ้น 10 เท่า สะดวกตอนทดสอบระบบโตและออกลูก
- **เพิ่มปลาชนิดใหม่**: เพิ่ม object ใน `FISH_SPECIES` (`src/data/fish.js`) แล้วกำหนด `look` สำหรับโมเดลชั่วคราว
- **เลิกขายปลาชนิดไหน**: ใส่ `retired: true` ที่สายพันธุ์นั้น (เลิกขายแล้ว: ปลาทอง ปลานีออน ปลาขี้ตังเหลือง ปลาขี้ตังน้ำเงิน ปลาหางนกยูง ปลาการ์ตูน ปลากัด ปลาเทวดา ปลาคาร์ป ปลาปอมปาดัวร์ ปลาสิงโต)
  ห้ามลบ object ออกจาก `FISH_SPECIES` เพราะปลาเดิมในเซฟของผู้เล่นจะหายตอนโหลด
- **เพิ่มของตกแต่ง**: เพิ่มใน `DECOR_ITEMS` แล้วเลือก `placeholder` จากชนิดที่มีอยู่
  (`vallis`, `fern`, `stem`, `grass`, `rock`, `driftwood`, `castle`, `chest`, `coral`, `bubbler`)
- **ดีบัก**: เปิด DevTools แล้วพิมพ์ `game` เพื่อดูสถานะ (การแก้ตัวเลขเงินใน `game.state` ไม่ถูกบันทึก เพราะเซฟถูกคำนวณใหม่จากคำสั่งบนเซฟล่าสุดเสมอ)
- **เริ่มเกมใหม่**: ตั้งค่า → รีเซ็ตเซฟ (มีผลทุกอุปกรณ์ สำรองให้ก่อนอัตโนมัติ)
