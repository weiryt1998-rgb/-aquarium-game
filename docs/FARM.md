# 🐄 ฟาร์มนอกบ้าน — โครงสร้างและแผนงาน

เกมมี 2 สถานที่ ใช้ renderer / กล้อง / เซฟ / เหรียญ ร่วมกัน แต่เป็นคนละ `THREE.Scene`

| สถานที่ | `game.location` | ฉาก | เข้าจาก |
| --- | --- | --- | --- |
| ในบ้าน (ตู้ปลา) | `'home'` | `sceneMgr.scene` (Room + Aquarium + Sunflower) | ปุ่ม 🏠 เข้าบ้าน · แตะประตูบ้านในฟาร์ม |
| นอกบ้าน (ฟาร์ม) | `'farm'` | `world/Farm.js` (สร้างครั้งแรกตอนออกไป) | ปุ่ม 🚪 นอกบ้าน |

- `Game.goTo(location)`: จอมืดลง → สลับฉาก (`SceneManager.showScene`) + ตั้งกล้อง (`frameTank` / `frameArea`) → สว่างขึ้น
- ระหว่างอยู่นอกบ้าน **ตู้ปลายังทำงานต่อ** (Simulation Engine, แจ้งเตือน, เหรียญ) แค่ไม่ได้เรนเดอร์ห้อง
- สถานที่ไม่ถูกบันทึกในเซฟ: เข้าเกมใหม่เริ่มในบ้านเสมอ
- HUD: ปุ่มที่มี `data-at="home"` / `data-at="farm"` แสดงเฉพาะสถานที่นั้น และคลาส `.at-farm` ซ่อนแถบสถานะ/ปุ่มให้อาหารของตู้ (`main.css`)

### เพศและการผสมพันธุ์

- **ผสมพันธุ์ได้เฉพาะวัวบราห์มัน**: สายพันธุ์ที่มี `canBreed: true` ใน `data/animals.js` (`brahman`, `brahman_calf` ที่โตแล้ว — ตรวจด้วย `canBreed(c)` = `adultBreedOf(c).canBreed`) · ตัวผู้ซื้อได้เฉพาะสายพันธุ์นี้ (`buyCow` อื่น ๆ + `sex: 'm'` → `invalid`/`sex`)
- โฮลสไตน์และเจอร์ซีย์เป็นโมเดลชั่วคราว ตั้ง `retired: true` แล้ว: ซื้อไม่ได้ (`buyCowBlock` → `invalid`) แต่ยังอยู่ในข้อมูล วัวในเซฟเก่ายังเลี้ยง/รีดนม/ขายได้ตามเดิม (ผสมพันธุ์ไม่ได้)

- ฟิลด์ต่อวัว (เซฟเก่าไม่มี = ค่าเริ่มต้นจาก `sanitizeFarm`): `sex` `'f'`/`'m'` (ไม่มี = `'f'` วัวเดิมเป็นแม่วัวนมทั้งหมด) · `preg` เวลาเริ่มท้อง (0 = ไม่ท้อง) · `bredAt` เวลาผสมครั้งล่าสุด (ทั้งสองเพศ) · `born` เวลาเกิดในฟาร์ม (0 = ซื้อมา) — Rules ไม่ตรวจคีย์รายตัว จึงไม่ต้องแก้ `firestore.rules`
- นมผลิตเฉพาะแม่วัวที่โตแล้ว (`cowAt` / `farmAt`) · รีดนมพ่อพันธุ์ → `cowBlock('milk')` = `'male'`
- `breedBlock(cow, bull, now)` → `not-found` · `dead` · `breed` (สายพันธุ์ผสมไม่ได้) · `not-female` · `not-male` · `young` · `pregnant` · `cooldown` · `weak` → `applyBreed` (แม่ได้ `preg` + `bredAt`, พ่อได้ `bredAt`)
- `dueAt(c)` = `preg` + `gestationHours` · `birthBlock(farm, cow, now)` → `not-found` · `dead` · `not-pregnant` · `not-ready` · `limit` · `remove-dead` → `newCalf` (สายพันธุ์ `adultBreedOf(แม่)`, `born` = เวลาคลอด) + `applyBirth` (แม่ `preg` = 0)
- ลูกวัวเกิดในฟาร์ม: `grownAt` = `born` + `growHours` (48 ชม.) · ระหว่างนั้น `isCalf` = true (ไม่ให้นม ผสมไม่ได้) · หน้าตาใช้ `adultBreedOf(c).young` ใน `data/animals.js` (ลูกวัวบราห์มันที่ซื้อ `brahman_calf` ก็ใช้ `brahman.young`)
- การตั้งท้องไม่มีผลอื่นกับการจำลอง · ค่าทั้งหมดอยู่ที่ `CONFIG.farm.breeding`
- ฝั่งตรวจ (`strict: false`) เผื่อค่าสุขภาพ/อิ่ม 2 หน่วย และเวลา 3 วินาที (ครบกำหนดคลอด / ช่วงพัก)
- รหัสข้อผิดพลาดของคำสั่ง (`BREED_FAIL` ใน commands.js): `not-found` → `not-found` · `young` `pregnant` `cooldown` `weak` `not-ready` → `cooldown` · `limit` `remove-dead` → `limit` · อื่น ๆ → `invalid`

### หญ้าในคอก (`farm.grass = { at, g: [24], w: [24] }`)

- คอกแบ่งเป็น 6×4 = 24 แปลง (`GRASS_AREA`, `patchAt`, `patchCenter` ใน `shared/farm.js`) แต่ละแปลงมีหญ้า `g` 0..100 และความชื้นดิน `w` 0..100
- `farmAt` เดินเวลาวัวทุกตัว + หญ้าพร้อมกันทีละ 5 นาที: วัวที่อิ่มไม่ถึง 90% เล็มหญ้า 25 หน่วย/ชม. จากแปลงที่ `pickPatch` เลือก (หญ้ามากสุด + ค่าสุ่มคงที่ต่อวัว-แปลง วัวจึงกระจายกันกิน) ได้ความอิ่ม 0.4/หน่วย (≈ 10%/ชม. เทียบหิว 12%/ชม.)
- หญ้างอก 20/ชม. เฉพาะตอนดินชื้น · ความชื้นลด 12/ชม. · ค่าทั้งหมดอยู่ที่ `CONFIG.farm.grass`
- วัวแย่งหญ้ากัน ค่าของแต่ละตัวขึ้นกับตัวอื่น → ทุกคำสั่งของฟาร์ม (`feedCow` `milkCow` `sellCow` `waterGrass` `breedCow` `birthCalf`) เดินเวลาทั้งฟาร์มก่อน (`settleFarm` ใน commands.js) · `cowAt` เดี่ยว ๆ เหลือไว้สำหรับกฎที่ไม่มีหญ้า
- ฉาก 3 มิติ (`world/Grass.js`): ดินใต้แปลงสีตามความชื้น · กอหญ้า InstancedMesh เดียวทั้งคอก (กอหายตามหญ้าที่เหลือ ตำแหน่งคงที่) · หยดน้ำตอนรด · วัวที่หิวเดินไปเล็มแปลงเดียวกับที่สูตรให้กิน (`grazePatch` → `Cow.grazeSpot`) หญ้าจึงหายตรงที่วัวยืน
- เซฟเก่าที่ยังไม่มี `grass` = หญ้าเต็ม ดินชื้น 40% ตั้งแต่เวลาของวัวตัวแรก (`grassOf`)

- ทุกอย่างเดินตามนาฬิกาจริง (`cowAt`): หิว 12%/ชม. → ท้องว่างแล้วสุขภาพลด 5%/ชม. จนตาย · อิ่มอยู่ = สุขภาพฟื้นและนมเพิ่มตามสายพันธุ์
- ราคา/รางวัลคิดฝั่งตรวจเสมอ ไม่รับตัวเลขจากเครื่อง · เวลาที่ทำในเครื่อง (`c.at`) ใช้ได้แต่ไม่ล้ำอนาคต
- แจ้งเตือน: วัวหิว / ท้องว่าง / ตาย / นมเต็ม (ครั้งเดียวต่อการเปลี่ยนสถานะ ทำงานแม้อยู่ในบ้าน) + จุดแดงบนปุ่ม 🚪 นอกบ้าน และ 🐄 วัว
- ป้ายลอยเหนือวัว: 🌾 หิว · 🥛 นมเต็ม · 🤒 ป่วย
- เทสต์: `tests/unit/farm.test.js` (กฎ + คำสั่ง) · `tests/rules/rules.test.js` (โครง `farm` + งบนิพจน์ตอนมีครบ 7 ตู้) · e2e ข้อ 15g (ซื้อ/ขายผ่าน UI จริง เห็นตรงกัน 2 เครื่อง)

### Firestore Rules

`validFarm` ตรวจเฉพาะโครง (`{ cows: list ≤ 8, grass? }` — `grass` อนุญาตแค่ชื่อคีย์ ตรวจข้างในแล้วเกินงบ) — ตู้ปลาครบ 7 ตู้เต็มความจุใช้งบนิพจน์ 1000 ของ Rules ไปเกือบหมด
ตรวจรายตัวไม่พอ (ทดลองแล้วเกินงบ) ค่าของวัวแต่ละตัวถูกจัดการด้วย `sanitizeFarm` ทุกครั้งที่อ่านเซฟ
⚠️ งบนิพจน์เหลือน้อยมาก: ถ้าจะเพิ่มฟิลด์ระดับ `game` อีก ให้รัน `npm run test:rules` (ข้อ "ฟาร์มวัว: …7 ตู้เต็มความจุ") ก่อนเสมอ

⚠️ ต้อง `npm run deploy` (Rules) **ก่อน** ปล่อยเกมเวอร์ชันนี้ — Rules เดิมไม่รับคีย์ `farm` การบันทึกหลังซื้อวัวจะถูกปฏิเสธ (เช่นเดียวกับคีย์ `farm.grass`)
